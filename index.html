Fortnite Shorts Auto

Fortnite Shorts Auto is a personal desktop tool for preparing and uploading original Fortnite gameplay clips to my own YouTube channel.

Features

The application converts gameplay recordings into vertical videos using FFmpeg and uploads them through YouTube API Services with Google OAuth 2.0 authorization.

Access

This application runs locally on my personal computer. It is not publicly distributed and has no public login.

YouTube API Services

This application uses YouTube API Services.
