Fortnite Shorts Auto

Fortnite Shorts Auto is a personal desktop application for preparing and uploading my own Fortnite gameplay clips to my YouTube channel.

How it works

The application uses FFmpeg to convert gameplay recordings into vertical videos suitable for YouTube Shorts.

It uses the YouTube Data API v3 and OAuth 2.0 to upload videos to my own YouTube channel with my authorization.

Access

This application runs locally on my personal computer. It is not distributed to other users and does not offer public registration or login.
